# MobileHeal — product demo

Self-contained demo pages for MobileHeal, the self-healing mobile delivery platform.

| Page | What it is |
|---|---|
| [`index.html`](index.html) | The full product demo: opening countdown, problem → solution, mission control, the live service map, every use case, regression, the saved-persona call, the 1/0 crash walkthrough in Android Studio and app screenshots. |
| [`demo.html`](demo.html) | Mission control on its own — pick a use case and press Play. |

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to share a link.

The pages are encrypted (AES-256-GCM) and open only with the PIN you were given. Everything shown runs in the browser with simulated data; no backend is needed.
