What's inside

Added through OpenCode's own extension points — no fork to maintain, OpenCode updates keep working.

Rexi agent

Explains every agent's score, drafts feedback, and helps you reject, rerun or approve. It always asks before deciding.

Rexi reviewer

@rexi-reviewer checks your local diff the way Rexi's QA and Security agents will, before you push.

Slash commands

/rexi-fixes /rexi-why /rexi-reject /rexi-rerun /rexi-approve /rexi-status

Rexi tools (MCP)

Eight tools over your Rexi server: fixes, scores, feedback, approvals, governance, redaction and the pause switch.

Rexi theme

Teal, gold and night-navy, matching the Rexi app and the demo.

Safe by default

Never approves or pauses without your yes. Feedback is redacted. Releases still need a named approver.

Install in two minutes

macOS

Unzip Rexi-IDE-macOS.zip, then in Terminal:
cd Rexi-IDE-macOS && ./install-mac.sh

Open a project

opencode, press Tab to pick the Rexi agent, then /rexi-fixes.

Windows

Unzip Rexi-IDE-Windows.zip, then in PowerShell:
powershell -ExecutionPolicy Bypass -File .\install-windows.ps1

Open a project

opencode, press Tab to pick the Rexi agent, then /rexi-fixes.

The installer adds OpenCode if it's missing (Homebrew or npm on macOS; npm or Scoop on Windows), copies the Rexi agents, tools and theme, and asks for your Rexi server URL. It never overwrites your existing OpenCode settings. Needs Python 3.

Rexi is a passion project. OpenCode is an independent open-source project (MIT licence); this pack only adds configuration, agents, a theme and an MCP tool server. The terminal shown above is illustrative.
