    What's inside

    Everything you need to act on Autopilot fixes, next to your code.

    Rexi agent

    Explains every agent's score, drafts feedback, and helps you reject, rerun or approve. It always asks before deciding.

    Rexi reviewer

    Checks your local diff the way Rexi's QA and Security agents will, before you push.

    Fix inbox

    Every Autopilot fix with its confidence; open one to see why, reject, rerun or approve.

    Connected to Rexi

    Talks to your Rexi server for fixes, scores, feedback, approvals, governance, redaction and the pause switch.

    Rexi theme

    Teal, gold and night-navy, matching the Rexi app and the demo.

    Safe by default

    Never approves or pauses without your yes. Feedback is redacted. Releases still need a named approver.

    Install & launch with one command

    Builds Rexi IDE from the GitHub repo, installs it and opens it. Needs Git and access to the repo; Node.js is installed if missing. Run it again any time to update.

    macOS · Terminal
    git clone https://github.com/shreekrithi1/MobileHeal.git ~/MobileHeal 2>/dev/null || git -C ~/MobileHeal pull; bash ~/MobileHeal/desktop/install-mac.sh

    Preview builds are not code-signed yet. The script below runs with -ExecutionPolicy Bypass for this one install only; review it first and check with IT before running.

    Windows · PowerShell
    git clone https://github.com/shreekrithi1/MobileHeal.git $HOME\MobileHeal 2>$null; git -C $HOME\MobileHeal pull; powershell -ExecutionPolicy Bypass -File $HOME\MobileHeal\desktop\install-windows.ps1

    Rexi is a passion project. The terminal shown above is illustrative.
