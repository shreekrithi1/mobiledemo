What's inside

Everything you need to act on Autopilot fixes, next to your code.

Rexi agent

Explains every agent's score, drafts feedback, and helps you reject, rerun or approve. It always asks before deciding.

Rexi reviewer

Checks your local diff the way Rexi's QA and Security agents will, before you push.

Fix inbox

Every Autopilot fix with its confidence; open one to see why, reject, rerun or approve.

Connected to Rexi

Talks to your Rexi server for fixes, scores, feedback, approvals, governance, redaction and the pause switch.

Rexi theme

Teal, gold and night-navy, matching the Rexi app and the demo.

Safe by default

Never approves or pauses without your yes. Feedback is redacted. Releases still need a named approver.

Launch with one command

Run it from the project folder. It opens the Rexi IDE, or its installer the first time. On macOS it also starts the Rexi web portal.

macOS

In Terminal:
./start.command --ide

Opens Rexi IDE.app if it's installed; otherwise opens Rexi-IDE.dmg and launches the app from it.

Windows

In Command Prompt or PowerShell:
start.cmd --ide

Opens Rexi IDE if it's installed; otherwise runs Rexi-IDE-Setup.exe.

The script looks for the installer in Downloads/mobiledemo, Downloads and the project's dist folder. To use a different file, set REXI_IDE_DMG (macOS) or REXI_IDE_EXE (Windows) to its path.
